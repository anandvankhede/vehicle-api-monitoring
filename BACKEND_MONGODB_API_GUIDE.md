## Technology Stack

### Backend
- **Framework**: FastAPI
- **Database**: MongoDB 6.0+
- **ODM**: Motor (async MongoDB driver)
- **Authentication**: JWT tokens
- **Validation**: Pydantic
- **Password Hashing**: bcrypt
- **Testing**: pytest + pytest-asyncio
- **API Docs**: Auto-generated by FastAPI

### Frontend (Already Built)
- React + TypeScript
- Vite
- Axios/Fetch for API calls
- localStorage for token storage

## Database Schema (MongoDB)

### Collections (6 main collections)

#### 1. **users** (Admin users)
```javascript
{
  "_id": ObjectId,
  "username": string (unique, required),
  "email": string (unique, required),
  "password_hash": string (required),
  "role": string (default: "admin"),
  "is_active": boolean (default: true),
  "created_at": datetime (default: now),
  "updated_at": datetime
}
```

#### 2. **clients**
```javascript
{
  "_id": ObjectId,
  "company_name": string (required),
  "username": string (unique, required),
  "email": string (unique, required),
  "phone": string,
  "address": string,
  "password_hash": string (required),
  "is_active": boolean (default: true),
  "created_at": datetime (default: now),
  "updated_at": datetime
}
```

#### 3. **apis**
```javascript
{
  "_id": ObjectId,
  "name": string (required),
  "endpoint": string (required),
  "description": string,
  "category": string,
  "is_active": boolean (default: true),
  "created_at": datetime (default: now)
}
```

#### 4. **api_access** (Client API subscriptions)
```javascript
{
  "_id": ObjectId,
  "client_id": ObjectId (ref: clients, required),
  "api_id": ObjectId (ref: apis, required),
  "success_price_per_hit": float (required),
  "not_found_price_per_hit": float (required),
  "current_usage": integer (default: 0),
  "assigned_at": datetime (default: now),
  "expiry_date": date,
  "is_active": boolean (default: true)
}
// Unique index on (client_id, api_id)
```

#### 5. **api_requests** (Request logs)
```javascript
{
  "_id": ObjectId,
  "client_id": ObjectId (ref: clients, required),
  "api_id": ObjectId (ref: apis, required),
  "request_time": datetime (default: now, indexed),
  "response_status": string (enum: "success", "failed", "not_found"),
  "response_time": integer (milliseconds),
  "ip_address": string,
  "user_agent": string,
  "request_data": object (JSON)
}
// Index on (client_id, request_time)
// Index on (request_time)
```

#### 6. **invoices**
```javascript
{
  "_id": ObjectId,
  "invoice_number": string (unique, required),
  "client_id": ObjectId (ref: clients, required),
  "billing_period_start": date (required),
  "billing_period_end": date (required),
  "api_wise_usage": array [
    {
      "api_name": string,
      "success_requests": integer,
      "not_found_requests": integer,
      "success_cost": float,
      "not_found_cost": float,
      "total_cost": float
    }
  ],
  "subtotal": float (required),
  "gst_percentage": float (default: 18),
  "gst_amount": float (required),
  "grand_total": float (required),
  "currency": string (default: "INR"),
  "status": string (default: "pending"),
  "created_at": datetime (default: now),
  "paid_at": datetime
}
```

## API Endpoints to Create

### Phase 1: Authentication (Priority: HIGH)
**File: `app/routers/auth.py`**

#### 1.1 POST /api/v1/auth/login
**Purpose**: Admin/Client login  
**Request Body**:
```json
{
  "username": "string",
  "password": "string"
}
```
**Response**:
```json
{
  "access_token": "jwt_token_string",
  "token_type": "bearer",
  "user": {
    "id": "string",
    "username": "string",
    "email": "string",
    "role": "admin/client"
  }
}
```
**Frontend Integration**: Login page (`src/pages/Login.tsx`, `src/pages/ClientAuth.tsx`)

---

### Phase 2: Client Management (Priority: HIGH)
**File: `app/routers/client.py`**

#### 2.1 GET /api/v1/clients
**Purpose**: List all clients (admin only)  
**Query Params**: `page`, `page_size`, `search`  
**Response**: Array of client objects  
**Frontend Integration**: Client management page

#### 2.2 POST /api/v1/clients
**Purpose**: Create new client (admin only)  
**Request Body**: Client details + password  
**Response**: Created client object  
**Frontend Integration**: Add client form

#### 2.3 GET /api/v1/clients/{client_id}
**Purpose**: Get client details  
**Response**: Single client object  
**Frontend Integration**: Client details page

#### 2.4 PUT /api/v1/clients/{client_id}
**Purpose**: Update client  
**Request Body**: Updated fields  
**Response**: Updated client object  
**Frontend Integration**: Edit client form

#### 2.5 DELETE /api/v1/clients/{client_id}
**Purpose**: Delete client (soft delete)  
**Response**: Success message  
**Frontend Integration**: Client management page

---

### Phase 3: API Management (Priority: HIGH)
**File: `app/routers/api_access.py`**

#### 3.1 GET /api/v1/clients/{client_id}/apis
**Purpose**: Get client's subscribed APIs  
**Response**: Array of API access objects with pricing  
**Frontend Integration**: Client services page

#### 3.2 POST /api/v1/clients/{client_id}/apis
**Purpose**: Assign API to client  
**Request Body**:
```json
{
  "api_id": "string",
  "success_price_per_hit": 0.5,
  "not_found_price_per_hit": 0.1
}
```
**Response**: Created access object  
**Frontend Integration**: Request access modal

#### 3.3 DELETE /api/v1/clients/{client_id}/apis/{api_id}
**Purpose**: Remove API access  
**Response**: Success message  
**Frontend Integration**: Client services page

#### 3.4 GET /api/v1/apis
**Purpose**: List all available APIs  
**Response**: Array of API objects  
**Frontend Integration**: Request access form

## Testing Each API

### Step-by-Step Testing Process

#### For Each API Endpoint:

1. **Start MongoDB**
   ```bash
   mongod --dbpath /path/to/data/db
   ```

2. **Start FastAPI Server**
   ```bash
   uvicorn app.main:app --reload --port 8000
   ```

3. **Access Auto-Documentation**
   - Open browser: `http://localhost:8000/docs`
   - FastAPI provides interactive testing interface

4. **Test Authentication First**
   ```json
   // POST /api/v1/auth/login
   {
     "username": "admin",
     "password": "admin123"
   }
   ```
   - Copy the `access_token` from response
   - Click "Authorize" button and enter: `Bearer <access_token>`

5. **Test Each Endpoint in Order**
   - Use the interactive docs to test
   - Verify response format matches frontend expectations
   - Check status codes (200, 201, 400, 401, 404, 500)

6. **Use Thunder Client/Postman**
   - Create collection with all endpoints
   - Test with different scenarios
   - Save requests for regression testing

### Example Test: Daily Report API

**Request:**
```
GET /api/v1/reports/daily?start_date=2024-01-01&end_date=2024-01-31&client_id=CLIENT_ID
Authorization: Bearer <token>
```

**Expected Response:**
```json
[
  {
    "date": "2024-01-15",
    "success_requests": 150,
    "failed_requests": 10,
    "not_found_requests": 5,
    "total_requests": 165,
    "cost": 78.5
  }
]
```

**Validation:**
- [ ] Returns array
- [ ] Each object has required fields
- [ ] Dates are within range
- [ ] Client filtering works (if client_id provided)
- [ ] Response time < 500ms
