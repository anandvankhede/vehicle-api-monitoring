# 01 Admin User Guide

## Introduction

**Vehicle API Monitoring System** (referred to as "Challan-Pay" in this documentation) is a web application used to monitor, track, and manage API usage across client organizations. The system provides insights into API request patterns, success rates, failure reasons, and usage analytics through dashboards and reports.

### What the Application Does
- Tracks API requests made by client companies
- Records request status: success, not found, failed
- Provides dashboard statistics for admin overview
- Allows clients to view their own API usage and analytics
- Manages API access requests and approval workflow
- Generates usage reports and billing invoices
- Stores raw API response data for analysis

### What an Admin Can Do
- View dashboard summary statistics (total clients, total APIs, health status)
- Monitor API usage across all clients
- Manage client companies and user accounts
- Approve or reject API access requests
- Assign APIs to clients with pricing and limits
- Generate usage reports and export data
- View audit logs and activity records
- Configure system settings

### General Application Workflow
1. Admin logs in via the login page
2. Admin is taken to the admin dashboard (/dashboard)
3. Admin can navigate between tabs to view different data sections
4. Admin can filter data by client, API, date range, and status
5. Admin can export data or generate reports
6. Admin can manage clients, APIs, and access requests
