# 04 Reporting and Exports Guide

## Purpose
Generate and view usage reports for API consumption.

## What You See
- **Report Selection**: Choose report type (daily usage, monthly billing, API stats, detailed table)
- **Report Data**: Tables and charts showing usage statistics
- **Export Options**: Generate and download reports in various formats

## Available Actions
- Select report type from tabs or dropdown
- Apply filters (client, date range, API, status)
- Generate the report
- Export to CSV, Excel, or PDF

## Filters (varies by report type)
- **Client ID**: Filter by specific client or "all clients"
- **Date Range**: Preset ranges (today, this week, this month, this year, all) or custom dates
- **API Name**: Filter by specific API
- **Status**: Filter by success, failed, not found, or all
- **Start/End Date**: For custom date ranges

## How to Use
1. Navigate to the Usage Reports tab
2. Select the type of report you want to generate
3. Apply the desired filters (client, date range, API, status)
4. The report data will load based on your selections
5. Use the export/download button to save the report

## Expected Result
- Report data loads showing the selected metrics
- Summary statistics are displayed (total requests, success rate, etc.)
- Export generates a file with the report data
- Different report types show different data structures

## Important Notes
- Reports can be generated for specific clients or all clients combined
- Date range affects which data is included in the report
- Export format depends on the report type (CSV for data tables, Excel for billing reports)
- Some report types may require admin privileges
